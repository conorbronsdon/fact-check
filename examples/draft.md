# Why agent memory is the next bottleneck

Every team I talk to has the same complaint: the agent forgets.

According to a 2025 Stack Overflow survey, 84% of developers now use AI tools in their work. That is up from 76% a year earlier. Context windows have grown more than 30x since 2023, and the largest now hold over a million tokens.

Anthropic was the first lab to ship a memory tool for agents. "Memory is a curation problem, not a storage problem," one founder told me.

I think this is the most underrated problem in the stack.
